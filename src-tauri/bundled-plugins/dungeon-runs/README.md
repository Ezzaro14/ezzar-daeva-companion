# Dungeon Runs

A run is one visit to a dungeon, from entering it to leaving. Each run shows:

- its **clear time** (entering to the end of the last boss fight) and how long you were in;
- every **boss fight** the meter saved in it, with your DPS and the party's;
- each member's **damage**, **DPS** across the run's boss fights, and **deaths**.

**Copy for chat** puts a one-line summary on the clipboard, to paste in the game's chat. Past runs are kept (the last 100).

Comes with the meter; needs the `feed:combat` permission (plugins/bundled.rs).
