# Notices

Every module's alerts as a popup over the game: Event Timers' events and world bosses about to start, and anything else a module says with `a2.notify`. Up to three at a time, newest on top, each kept a few seconds; the recent ones are listed. A module can keep one up until it says otherwise (Event Timers' hidden cube, until it is opened); those have no countdown bar and aren't pushed out by newer ones. Place the popup with **Edit layout** in the dashboard.

Comes with the meter (plugins/bundled.rs).
